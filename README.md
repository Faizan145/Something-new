## How to Use
1. Put all files (HTML, CSS, JS + assets) in one folder.
2. Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox).
3. Everything works **100% offline** – no internet required.

## Features
- Cinematic loading → 3D Gift Box → Birthday Announcement → Love Note → Photo Gallery → Video → Emotional Ending
- Floating glassmorphism music control (never autoplays, continues across pages)
- Twinkling stars, 3D moon, clouds, floating hearts, rose petals, golden particles, fireflies, fireworks
- Luxury custom cursor, glassmorphism, page fades, 3D gift open, line-by-line note reveal
- Fully responsive (mobile + desktop)
- Pure HTML + CSS + Vanilla JS – zero libraries / CDNs

## Tips
- Use high-quality photos (square or portrait work best).
- Video should be muted-friendly (no dialogue needed).
- Choose a soft romantic instrumental for `music.mp3`.
